## 🌟 Key Features

- 🌈 **Interactive Color Picker**: Instant background color transformation upon clicking curated color swatches.
- 📋 **One-Click Clipboard Copy**: Instantly copy HEX and RGB color values.
- 🌀 **Random Color Generator**: Generate fresh, high-contrast color combinations with one click.
- 📱 **Responsive Interface**: Clean layout optimized for mobile and desktop screens.
